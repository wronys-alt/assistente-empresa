# Estratégia — Método Rumo

Aqui ficam a bússola do negócio e os ciclos de 13 semanas, criados com `/metodo-rumo`.

| Ritual | Comando | Quando |
|---|---|---|
| Bússola do negócio | `/metodo-rumo bussola` | Uma vez, revista a cada semana 13 |
| Plano do trimestre | `/metodo-rumo plano` | No início de cada ciclo |
| Revisão semanal | `/metodo-rumo semana` | Toda sexta ou segunda |
| Revisão mensal | `/metodo-rumo mes` | Ao fim das semanas 4, 8 e 12 |
| Revisão do ciclo | `/metodo-rumo ciclo` | Na semana 13 |
| Organizar o dia | `/metodo-rumo dia` | Quando quiser |

Cada ciclo ganha uma pasta própria, por exemplo `ciclo-2026-04/`.
